# חלקים מאיתנו 💞🧩

מירוץ פאזל בזמן אמת — שניים עד שישה מחשבים, התמונות שלכם, ומי שמרכיב/ה ראשון/ה מנצח/ת.

## להפעלה

> הורדתם מ-GitHub? לוחצים פעמיים על **`start.cmd`** שבתיקיית הפרויקט (או מריצים `npm install && npm run play`), ושמים את התמונות שלכם בתיקייה `photos`.

1. במחשב אחד (המארח/ת) לוחצים פעמיים על **`חלקים מאיתנו - הפעלה.cmd`** שבתיקייה `משחק זוגי`.
   - בפעם הראשונה זה מתקין ובונה את המשחק (דקה או שתיים). מהפעם השנייה זה עולה מיד.
   - אם Windows שואל על גישה לרשת — בוחרים **אפשר** (רשתות פרטיות). בלי זה שאר המחשבים לא יוכלו להתחבר.
2. הדפדפן נפתח לבד. כותבים שם, בוחרים דמות וצבע, ולוחצים **פותחים חדר חדש**.
3. בחדר בוחרים **כמה שחקנים** (2–6). מופיעים כתובת (למשל `http://192.168.0.100:5200`) וקוד של 4 ספרות.
4. בכל מחשב נוסף — **באותה רשת WiFi** — פותחים את הכתובת בדפדפן ומקלידים את הקוד. יש גם QR לטאבלט.

החלון השחור של השרת נשאר פתוח לאורך המשחק. בסוף סוגרים אותו.

## איך משחקים

- כל שלב **מכפיל** את מספר החלקים: **9 ← 18 ← 36 ← 72 ← 144** (ובמסלול "אגדה" גם 288).
  הלוח תמיד ריבוע, אז בשלבים 18, 72 ו־288 החלקים מלבניים.
- כולם מקבלים **אותה תמונה ואותו ערבוב בדיוק**. שלוש שניות לשנן את התמונה — ויוצאים לדרך.
- **גוררים חלק על חלק** כדי להחליף ביניהם, או לוחצים על חלק ואז על המקום שלו.
- מי שמרכיב/ה ראשון/ה לוקח/ת את השלב, וברגע הזה השלב נגמר לכולם. הזמן נמדד בכל מחשב בנפרד, כך שהרשת לא משפיעה על ההכרעה.
- בסוף כל שלב יש טבלת דירוג 🥇🥈🥉, ומי שסיים/ה אחרון/ה מקבל/ת **כרטיס אהבה** 💌 — משימה קטנה ומתוקה.
- בסוף: האלוף/ה של הערב, **הפרס** שכל אחד בחר מראש, **הפתקים הסודיים** נחשפים, ואלבום התמונות של הערב.

### כמה שחקנים

המארח/ת קובע/ת בלובי עד כמה שחקנים (2–6). כל מחשב שנכנס עם הקוד תופס מקום פנוי, ומתחילים כשכולם אישרו מוכנות.
מי שהתנתק/ה ולא חוזר/ת — המארח/ת יכול/ה לפנות את המקום בלחיצה, והמשחק ממשיך בלעדיו.

### רמת עזרה — כל אחד בוחר לעצמו

- 🔥 **אלופים** — בלי סימון לחלקים שהגיעו למקום ובלי תמונת עזר.
- ⚖️ **רגיל** — חלק שהגיע למקום ננעל ונדלק, ויש תמונת עזר.
- 🌸 **בנחת** — כמו רגיל, ועוד רמז קטן כשנתקעים.

ככה גם כשאחד מהיר יותר, המירוץ נשאר צמוד.

### 😈 מצב שובבות

כל כמה חלקים שננעלים מתמלא מד ומקבלים כוח (עד שניים בכל רגע). מפעילים בלחיצה או במקשים **1** / **2** (או רווח).
כוחות התקפה פוגעים תמיד **במי שמוביל/ה** באותו רגע, וכולם רואים מי שלח למי.

| כוח | מה הוא עושה |
|---|---|
| 💘 גשם לבבות | לבבות מציפים את הלוח של המוביל/ה |
| 🌫️ ערפל אהבה | הלוח של המוביל/ה מיטשטש לכמה שניות |
| 🌀 סחרור | מחליף אצל המוביל/ה שני חלקים שעוד לא במקום |
| 🧊 הקפאה | שתי שניות שבהן אי אפשר להזיז כלום |
| 👁️ הצצה | רואים לרגע את התמונה השלמה על הלוח |
| 🧲 מגנט | חלק אחד קופץ ישר למקום |

### ועוד

- **אימוג׳ים** ❤️ 😘 😂 עפים למסך של כל השחקנים באמצע המירוץ.
- במשחק של שניים רואים את **המפה** של היריב/ה (איפה כבר הצליח/ה — בלי התמונה עצמה). בקבוצה רואים טבלת מובילים חיה.
- **אימון לבד** מהמסך הראשי, עם שיאים אישיים לכל גודל לוח — כולל 288 חלקים.
- המוזיקה והצלילים נוצרים בזמן אמת. המוזיקה כבויה כברירת מחדל; מדליקים בכפתור ♫ למעלה.
- נפל החיבור או שרעננתם את הדף? המשחק מתחבר מחדש לבד וממשיך מאיפה שעצרתם.

## תמונות

- **מהתיקייה** — כל JPG/PNG בתיקייה `משחק זוגי/photos` נכנס לבד. קבצים בשם `us-…` נחשבים "שלנו" ומקבלים עדיפות.
- **מהמחשב** — בחדר לוחצים "העלאה מהמחשב". התמונות נחתכות לריבוע ונשמרות רק בדפדפן, לא עולות לשום אתר.
- **פרימיום 💎** — ארבע תמונות שנוצרו במיוחד למשחק: ירושלים בשעת הזהב, פטיסרי לשניים, סמטה כחולה בצפת ושוק הפרחים (`pieces-of-us/public/premium`). כש"גמר פרימיום" פועל, השלב האחרון נבנה מאחת מהן. כדי להוסיף: מעתיקים לשם JPG מרובע ומוסיפים שורה ב־`manifest.json`.
- במצב **הפתעה** המשחק שולח את התמונות העשירות בפרטים ללוחות הגדולים, כדי שגם 144 חלקים יהיו קשים אבל הוגנים.

## בעיות נפוצות

- **מחשב לא מתחבר** — ודאו שכל המחשבים באותו WiFi, שהחלון השחור פתוח, ושאישרתם גישה ב-Windows Firewall.
- **"החדר מלא"** — כל המקומות תפוסים. המארח/ת יכול/ה להגדיל את מספר השחקנים בלובי או לפנות מקום של מי שהתנתק/ה.
- **"לא מצאנו חדר"** — החדר נסגר (המארח/ת יצא/ה). פותחים חדר חדש.
- **שיניתם קוד?** בתיקייה `pieces-of-us` מריצים `npm run play` — זה בונה מחדש ומפעיל.

## למפתחים

- `npm run dev` — פיתוח: Vite על פורט 5173 ושרת החדרים על 5200.
- `npm run play` — בנייה והפעלה על פורט 5200. `npm run typecheck` — בדיקת טיפוסים.
- מבנה:
  - `server/index.mjs` — שרת מקומי: מגיש את המשחק ואת `photos/`, ומנהל חדרים ב-WebSocket (עד 6 בחדר).
  - `src/game/engine.ts` — מנוע המשחק. רץ אצל המארח/ת והוא מקור האמת; כל המערכים מאונדקסים לפי `slot` של השחקן.
  - `src/game/constants.ts` — `LADDER` (סולם ההכפלה), המסלולים, הכוחות וכרטיסי האהבה.
  - `src/game/usePuzzleRound.ts` — הלוח של שחקן אחד: החלפות, רצפים, כוחות, רמזים וסיום.
  - `src/game/controller.ts` — מחבר בין הרשת, המנוע והממשק, ומעביר תמונות בין המחשבים.
  - `src/net/` — שכבת רשת עם שני מימושים: שרת מקומי ו-Supabase.
  - `src/components/game/PuzzleBoard.tsx` — הלוח עצמו (עמודות × שורות): גרירה ישירה ב-DOM, אנימציות ב-CSS.
  - `src/lib/sound.ts` — סינתיסייזר של צלילים ומוזיקה ב-Web Audio.
- מעבר ל-Lovable: ראו [`LOVABLE.md`](LOVABLE.md).
