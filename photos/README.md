# התמונות שלכם

כל קובץ **JPG / PNG / WEBP** שתשימו בתיקייה הזו נכנס למשחק לבד (התיקייה נטענת בכל הפעלה של השרת).

- קובץ שמתחיל ב־`us-` נחשב "תמונה שלנו" ומקבל עדיפות בבחירת התמונות לשלבים.
- קובץ שמתחיל ב־`sweet-` נכנס לקבוצת "מתוקים" (קינוחים, מקומות, כל מה שנחמד).
- תמונות מרובעות נראות הכי טוב, אבל כל יחס גובה־רוחב עובד.

התמונות נשארות על המחשב שלכם בלבד: השרת המקומי מגיש אותן לשאר המחשבים ברשת הביתית, והן לא עולות לשום שרת חיצוני.
אפשר גם להעלות תמונות ישירות מתוך המשחק ("העלאה מהמחשב") — אלה נשמרות בדפדפן ועוברות ישירות לשאר השחקנים.

> אם קיימת תיקיית `photos` ליד תיקיית המשחק (`../photos`), היא זו שנטענת.
